# FYP documentation

Put university report / thesis drafts here (chapters, abstract, screenshots for the PDF report).

- Engineering how-to stays in the parent `docs/` folder (and is public on GitHub).
- This folder is for **narrative FYP writing**, not API setup steps.

You can start with files like:

- `abstract.md`
- `chapter-01-introduction.md`
- `screenshots/` (optional)

Nothing required here until you start the written report.
